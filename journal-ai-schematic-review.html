讓 AI Agent 先協助 EE 檢查線路圖

目標不是讓 AI 取代工程師，而是先處理重複檢查，讓經驗留在真正需要判斷的地方。

從一個實際題目開始

我收到的題目很直接：能不能用 AI Agent 幫 EE 先檢查線路圖？我先讓 Agent 讀取電路結構，再從腳位方向、命名差異、跨通道共用電路與元件組成開始整理可能有問題的地方。

Agent 先做什麼

  • 比對腳位方向與連接關係。
  • 找出相似訊號或通道之間的命名差異。
  • 檢查應共用或應隔離的電路結構。
  • 把疑點依類型整理，而不是直接宣判錯誤。

Agent 的輸出是待確認清單，EE 再依照設計意圖逐項判斷。這個順序很重要，因為線路圖裡很多看似不一致的地方，可能正是設計者刻意做出的選擇。

AI 負責先找出值得看的地方，工程師負責判斷它是不是問題。

讓回饋改善下一輪

工程師確認誤報或漏報後，這些結果可以回到規則、提示與檢查順序中。Agent 的價值不只在第一次掃描，而是在每次回饋後，逐漸把重複檢查做得更準確。
