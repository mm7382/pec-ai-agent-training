公開實作案例 · AI AGENT WORKFLOW

讓 AI Agent 使用可審核的共用知識

當不同任務都需要參考過去的決策與做法，關鍵不只是讓 AI「記得」，而是讓資料有來源、更新有審核、使用前能查證。

Michael Agent Lab 的個人工作流示例 · 非客戶專案

要解決的問題

AI Agent 在不同任務中工作時，先前確認過的規則、判斷與成果容易散落在各自的對話裡。下一次執行若只憑當下對話，可能重問同一題，也可能沿用已過期的答案。

這個個人實作將知識的查找與更新放進工作流程，讓 Agent 在行動前先查既有資料；新發現則必須經過人確認，才進入正式知識來源。

實作流程

  1. 查找既有資料
    先找與任務相關的規則、先前決策和來源，再決定下一步。
  2. 執行並保留依據
    按已確認的規則處理任務；碰到衝突或資訊不足時，標出待判斷處。
  3. 提交新經驗
    值得保留的做法先進待審核區，附上來源與適用範圍。
  4. 人工審核後更新
    檢查敏感資料、重複或矛盾內容，再決定是否納入正式知識。

驗收時看什麼

  • Agent 是否能指出採用哪份既有資料與理由。
  • 資料不足時，是否把不確定處交回人工確認。
  • 新內容是否經審核才成為後續任務可引用的知識。

可觀察的成果：這套流程把「先查資料」和「更新需審核」設為固定步驟。此頁沒有宣稱節省多少時間，也沒有把個人實作當作客戶成效。

這個案例能怎麼套用

需要跨任務沿用知識的團隊，可以先選一類重複工作，確認資料來源與負責審核的人，再用少量真實案例測試查找、執行與更新流程。若資料涉及敏感資訊，應先決定哪些內容可以進入知識庫。
