2. 在該資源的「Sitemaps」確認 `https://mm7382.github.io/sitemap.xml` 與 `https://mm7382.github.io/sitemap-lab.xml` 是否已提交及成功讀取。`robots.txt` 已列出兩份網站地圖，但被發現不等於在 Search Console 有提交紀錄。
